# SleepWell_APP

Android 수면 기록·개인화 수면 계획 앱 **SleepWell 통합 v8**입니다. Samsung Health가 Health Connect에 공유한 수면 기록을 누적하고, DATA33 수면 이력 특징과 Two-Process 수리 특징을 기기 내 HGB 하이브리드 예측에 사용합니다.

## v0.8.8 오프라인 HGB 하이브리드

실행 경로는 **DATA33 33개 + Two-Process 수리 특징 6개 → HGB → 기존 점진 개인화·권장 정책**입니다. CMI·MESA별 HGB 예측을 기존 앱 정책대로 결합합니다. 서버 연결과 TabDPT 학습 문맥이 필요하지 않습니다.

0.8.7의 경량 TabDPT 실행기·ONNX Runtime 의존성·학습 문맥 번들을 APK에서 제외했습니다. 기존 검증된 HGB 학습 모델 두 개(합계 456,000바이트)는 저장소에 포함하므로 별도 모델 다운로드 없이 앱을 빌드할 수 있습니다. 학습 행과 목표값으로 구성된 TabDPT context는 포함하지 않습니다. 과거 저장 결과의 TabDPT 출처 표시는 이력 보존을 위해 유지합니다.

수면 기록·설문·프로필·CSV·결과 스냅샷의 저장 형식, DATA33 계산식, GRADUAL_V1 점진 개인화, 워치 입력 정책, Health Connect 누적·백그라운드 동기화 및 기기 시간대 처리는 유지합니다. HGB 로딩 실패 시 기존 Two-Process 권장으로 처리합니다. 과거 CSV 재분석에서 실시간 예측기를 호출하지 않는 기존 정책도 유지합니다.

기존 비교 실험의 개인화 보정 후 입면·기상 평균 절대오차는 연구용 TabDPT 57.40분, 경량 TabDPT 57.59분, HGB 58.17분이었습니다(359명·2,848건, 코호트별 사람 평균을 50:50 결합). 앱의 결합 예측이나 권장 수면시간의 건강 효과를 검증한 지표는 아닙니다. 이번 전환은 정확도 향상 목적이 아니라 오프라인 실행 비용을 줄이기 위한 선택입니다.

HGB golden 회귀 테스트용 입력은 공개 저장소에 포함하지 않습니다. 허가된 로컬 검증 프로젝트가 있는 경우에만 다음으로 테스트 자산을 준비합니다. 일반 앱 빌드에는 필요하지 않습니다.

```powershell
.\tools\setup_legacy_hgb_tests.ps1 -LocalProjectDirectory "<검증된 로컬 프로젝트>"
```

## 화면과 주요 기능

- **오늘:** 오늘의 수면 준비, 최근 수면 구간·단계 그래프, 개인화 권장, 7일·30일 추세, 모델 추정 지수와 추천 근거.
- **기록:** 월간 달력에 실제 수면과 저장한 분석 결과를 구분해 표시합니다. 날짜를 누르면 수면 상세와 저장 결과를 바텀시트로 확인합니다.
- **내 정보:** 성별·생활 습관과 희망 수면시간을 관리합니다. 희망 수면은 시·분으로 직접 입력하며 연령대·직업 입력란은 없습니다.
- **자동 누적:** 전경 갱신과 기존 백그라운드 동기화를 유지합니다. 같은 기록의 중복 처리·출처·관측 시각을 보존합니다.
- **필요한 입력만 보완:** 센서에서 얻지 못한 피로도·개운함 등은 설문으로 보완합니다. 파일 가져오기와 직접 일지는 선택 사항입니다.

## v0.8.3 연령대 입력 제거

초기 설정과 내 정보에서 연령대 입력을 제거했습니다. 연령을 선택하지 않아도 설정을 완료할 수 있으며, 새 프로필에 임의의 연령을 채우지 않습니다.

- 기존 프로필의 연령 값은 호환을 위해 그대로 보존하며 다른 정보를 수정해도 지워지지 않습니다. 기존 저장 스냅샷도 변경하지 않습니다.
- 연령은 현재 예측·권장 수면시간의 입력 계수로 사용하지 않습니다. 기존의 관측 집단 평균은 참고 메타데이터이며 `used_for_target=false`를 유지합니다.
- 연령 평균을 추가한 별도 후향 실험에서도 명확한 예측 개선이 확인되지 않아 모델 자산·DATA33·점진 개인화 정책은 변경하지 않았습니다. 권장 수면시간의 건강 효과를 검증했다는 의미는 아닙니다.
- 기존 희망 수면시간 직접 입력, 수면 기록, 설문, Health Connect·백그라운드 동기화 및 기기 시간대 처리를 유지합니다.

## 실제 기록·추정·권장의 구분

- **실제 기록:** Health Connect/사용자 파일에서 읽은 수면 구간과 제공된 단계입니다. 단계가 없거나 측정이 불충분한 값을 임의로 채우지 않습니다.
- **모델 추정 지수:** 수면압·일주기 등의 모델 계산값입니다. 직접 측정한 생리 신호가 아닙니다.
- **권장 수면 기회시간:** 취침부터 목표 기상까지 확보하도록 제안하는 시간입니다. 실제 잠든 시간과 같은 값으로 표시하지 않습니다.
- **DATA33:** 축적된 수면 이력에서 계산하는 33개 특징입니다. 설문 33개 수집률이나 온라인 모델 재학습을 의미하지 않습니다.
- **피로도 척도:** 7점→5점 매핑은 기존 엔진 호환 규칙입니다. 두 척도의 심리측정적 동등성이나 성능 개선이 검증됐다는 뜻은 아닙니다.

스냅샷이 없는 예전 저장 결과는 기존 요약을 보여줍니다. 새 통합본에서 저장한 결과부터 당시 입력·결과를 함께 보관하며, 없는 과거 그래프를 추측해 생성하지 않습니다.

## CSV 과거 기록 재분석

CSV로 한 번에 가져온 과거 수면도 날짜별 DATA33과 개인화 예측에 반영합니다. 과거 분석에는 **CSV 기반 과거 재분석**이라고 표시하며, 현재 CSV와 내 정보로 다시 계산한 결과임을 안내합니다.

- 기기 시간대의 20시 기준과 화면에서 선택한 날짜의 종료 시각 중 더 이른 경계까지 사용합니다. 경계와 같은 시각 또는 그 이후에 끝난 수면, 이후에 저장한 설문은 제외합니다.
- CSV를 처음 가져온 실제 시각은 원본과 스냅샷에 보존합니다. CSV 재분석 호출 내부에서만 수면 완료 시각을 사용하며, 실시간 예측과 Health Connect 수신 정책은 유지합니다.
- 재분석을 저장하면 **저장된 CSV 기반 재분석**, 실시간 결과를 저장하면 **당시 저장된 예측**으로 구분합니다. 생성 방식이 없는 기존 결과에는 **저장된 결과 · 생성 방식 미기록**을 표시합니다.
- 저장 결과를 열 때는 당시 저장한 결과를 그대로 표시합니다. 같은 날짜의 재분석이 기존 예측을 덮어쓰지 않습니다.
- 모델 가중치·DATA33 계산식·점진 개인화 정책은 변경하지 않았습니다. 이 변경은 과거 CSV 입력 누락을 바로잡은 것이며 정확도 향상에 관한 새 성능 검증은 아닙니다.

CSV 과거 기록 재분석 수정은 **v0.8.1부터 포함**됩니다. 상단 다운로드 링크에서 수정된 APK를 받을 수 있습니다.

## 기기 시간대 적용 (v0.8.2)

새 입력과 수면 계획 계산, DATA33의 현지 시각 특징, 화면 표시는 기기의 현재 시간대를 사용합니다. 평소 `07:30` 기상은 현재 지역의 오전 7시 30분으로 해석합니다. 시간대 변경 시 계산을 갱신합니다.

기존 수면 기록의 절대 시각과 저장된 예측은 보존합니다. 이미 저장한 일정의 명시적 시각과 설문의 출처 시간대를 임의 이동하지 않습니다. 시간대 정보가 없는 과거 CSV·설문의 한국 시간 해석도 유지합니다. 연구 모델의 가중치는 변경하지 않았으며, 기존 한국 시간 연구 회귀와 실제 앱의 시간대 적용 경로를 분리해 검증합니다.

## 빌드 및 실행

먼저 위 스크립트로 검증된 경량 TabDPT 번들을 준비합니다. 그 다음 Android Studio에서 저장소를 열고 Android SDK 경로를 설정한 뒤 `app` 구성을 실행합니다. 로컬 SDK 경로와 모델 번들은 저장소에 포함하지 않습니다.

| 항목 | 설정 |
|---|---|
| Android SDK | min 29 / compile 37 / target 37 |
| Android Gradle Plugin | 9.4.0 |
| Gradle Wrapper | 9.7.1 |
| Kotlin Compose 플러그인 | 2.4.20 |
| Compose BOM | 2026.09.00 |
| Health Connect | 1.1.0 |
| ONNX Runtime Android | 1.22.0 |
| Gradle daemon JVM | 저장소 설정 25; 검증은 Android Studio 번들 JBR 사용 |
| Java source/target | 11 |

Windows PowerShell:

```powershell
.\gradlew.bat :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

macOS/Linux:

```bash
./gradlew :app:assembleDebug :app:assembleDebugAndroidTest :app:lintDebug
```

생성된 디버그 APK는 `app/build/outputs/apk/debug/app-debug.apk`에 있습니다. Health Connect 수면 읽기 권한이 필요하며 백그라운드 읽기는 지원 OS·권한·배터리 정책에 따라 실행 시점이 달라집니다. 앱 강제 중지 상태에서는 다시 앱을 열 때까지 동기화가 중단될 수 있습니다.

## v0.8.8 검증

- Android 에뮬레이터 회귀 테스트 **233개 통과**: 일반 217개 + 날짜·시간대 16개.
- 기존 학습 HGB와 Android 출력의 golden 일치, 28일 기록 → DATA33 → HGB → 점진 개인화 → 추천 카드·구간 표시를 확인했습니다.
- CSV 과거 재분석의 후일 기록 배제, 설문 복원·5/7점 척도, 저장 결과, 중복 처리·동시 저장, Health Connect 동기화 정책, 워치 입력, 시간대 회귀를 포함합니다.
- 앱·테스트 APK 빌드 및 lint 통과: **오류 0개, 경고 13개, 힌트 10개**. 남은 경고는 아이콘 미설정·백업 규칙·locale·의존성 버전 등 항목이며 이번 전환으로 모두 해소한 것은 아닙니다.
- A52s 휴대폰에 데이터 초기화 없이 0.8.8 업데이트·실행 성공. 최종 APK에서 HGB 실기기 검사 6개도 통과했고 기존 프로필을 보존했습니다. 설치 전 이 패키지에는 수면·설문 파일이 없었습니다.
- APK에서 TabDPT context·ONNX Runtime이 제외되고 기존 HGB 모델 두 개가 해시 일치함을 확인했습니다.
- 기존 저장소·DATA33·개인화 엔진·Health Connect·백그라운드 동기화·시간대 구현은 전환 전과 동일합니다. 과거 결과를 HGB 결과로 덮어쓰지 않습니다.

실제 Samsung Health/Galaxy Watch의 신규 기록 수신과 장시간 OS 백그라운드 동작은 이번 회귀 테스트와 별도입니다. 서버 연결이 필요한 과거 TabDPT live-server 검사와 화면 캡처 전용 검사는 이번 233개에 포함하지 않았습니다. 테스트용 수면 이력은 사용자 저장소에 저장하지 않았습니다.

이전 버전의 검증 이력은 [기존 검증 안내](docs/VALIDATION.md), 이번 배포 결과는 [v0.8.8 검증](docs/VALIDATION_0.8.8.md)을 참고하세요.

## 소스 구성

```text
app/src/main/java/app/sleepwell/
  analysis/   # 수면 누적, DATA33 연계, 설문·프로필·결과 보관, 동기화
  health/     # Health Connect·CSV 및 분석 인터페이스
  user/       # 모델·개인화·측정·권장 정책
  ui/         # 오늘·기록·내 정보와 그래프
app/src/main/assets/       # 공개 가능한 모델·명시적 데모 자산; TabDPT 번들은 로컬 준비
app/src/androidTest/      # 회귀 테스트와 격리된 fixture
gradle/                   # Wrapper 및 버전 카탈로그
tools/                    # 테스트 fixture 생성 도구
```

앱 코드·리소스·테스트·빌드 설정·개발 도구를 포함합니다. TabDPT 가중치·학습 문맥, 빌드 산출물, 로컬 SDK 설정, 인증정보, 실제 수면·설문 데이터와 검증 백업은 제외합니다. 저장소의 `demo_*` 파일은 명시적 데모/검증 자산이며 실제 사용자 기록이 아닙니다.
