## v8에 적용할 디자인 결정

1. **그래프를 홈에 상시 배치한다.** 연결 상태 다음에 `최근 수면` 그래프를 놓는다. 그래프는 더 이상 “상세 분석”에 숨기지 않는다. 기록이 있으면 수면 구간/단계 타임라인을, 기록이 없으면 축과 설명, 삼성 헬스 연결 행동을 표시한다.
2. **사실·추정·권장을 분리한다.** 실제 수면 기록은 청록 계열 실선/막대와 원천 라벨, 모델의 과거 계산은 계열별 실선, 미래 가정 예측은 같은 계열 점선, 권장 구간은 옅은 음영으로 그린다. 범례와 보조 텍스트가 이 차이를 반복한다.
3. **한 화면의 정보 위계를 고정한다.** (a) 선택 날짜와 동기화 상태, (b) 최근 수면과 그래프, (c) 오늘의 권장 취침·기상, (d) 최근 7/30일 추세, (e) 짧은 컨디션 확인 순서다. 세부 모델·DATA33은 `추천 근거`에 접는다.
4. **빈 데이터도 정직하게 보인다.** 빈 그래프에 0시간이나 임의 곡선을 만들지 않는다. 연결됨/권한 없음/동기화 중/기록 없음/일부 기록/오래된 기록/실패 상태의 문구와 행동을 구분한다.
5. **원천 조건을 존중한다.** SleepWell에서 실제로 보유한 시작·종료 시각은 수면 구간으로, 실제 단계 데이터는 단계 타임라인으로 표시한다. 수면압·일주기 곡선은 모델 추정임을 표시하고, 수면 단계나 생리 측정값처럼 보이게 하지 않는다.

## 시각 토큰 방향

- 배경: 밝은 모드의 옅은 청회색/백색, 어두운 모드의 깊은 남색.
- 텍스트: 가장 중요한 시간과 수면 기간은 큰 숫자, 설명은 짧은 한국어 문장.
- 관측 기록: 청록, 모델 추정: 라벤더, 권장 구간: 저채도 인디고 음영. 색만으로 구분하지 않고 선/막대 모양과 라벨도 쓴다.
- 카드: 동일한 여백·모서리·제목 위치를 유지하며 장식성 큰 그래디언트는 사용하지 않는다.
- 접근성: 본문 14sp 이상, 주요 터치 영역 48dp 이상, 텍스트 대비 4.5:1 이상을 목표로 한다. 그래프의 핵심 값은 화면 읽기용 텍스트 요약도 제공한다.

## 원천·제약

- Samsung Health의 공개 수면 화면은 Galaxy Watch/Ring을 전제로 하며, 단계·심박·호흡 등의 지원 여부는 기기와 권한에 따라 달라진다. 따라서 공개 UI는 데이터 가용성의 증거가 아니다. Samsung의 상세 주의사항은 위 공식 페이지와 [국내 지원 문서](https://www.samsungsvc.co.kr/solution/1273806)를 따른다.
- Sleep Cycle, Sleep as Android, Pillow의 스크린샷은 각 공식 스토어 등록 페이지에서 시각적으로 확인했다. 스토어 캡션과 소개문은 기능 범위를 확인하는 보조 증거일 뿐, SleepWell에 구현됐다는 뜻이 아니다.
- 공개 UI만 조사했다. 사용자 계정, 개인 수면 기록, 구독 기능 또는 앱 내부 화면에는 접근하지 않았다.
